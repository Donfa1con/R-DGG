# data/references/ — source portrait frames (attribution)

The 184 `<stem>.png` files in this directory are reference portrait frames from the
**Seamless Interaction** dataset (Meta / FAIR — `facebook/seamless-interaction`). That
dataset is licensed **CC BY-NC 4.0**. Each file is one frame from the ground-truth clip
of the matching stem. It is the source portrait that conditions every listener generator.

(https://creativecommons.org/licenses/by-nc/4.0/). Modification: single-frame extraction
from the source clips. Use is non-commercial only.

The ground-truth video and audio (`GT/LS_AL/`, `GT/LS_AL_wav/`) that `download_si184.py`
fetches come from the same dataset under the same license. They are not committed here.
